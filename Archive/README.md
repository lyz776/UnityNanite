# Archive / 归档

Historical validation captures, implementation notes, Unity template and recovery files, editor settings, temporary research files, and personal delivery documents were moved to `Archive/Local/` in this workspace. That folder is ignored by Git so generated and personal material is not published with the project.

历史验证截图、实现笔记、Unity 模板与恢复文件、编辑器设置、临时研究文件和个人交付文档已移至本地 `Archive/Local/`。该目录不会提交到 Git；此前受 Git 跟踪的文件仍可从仓库历史版本中找回。

New validation runs may recreate `Validation/`; its generated output is ignored.
