# TOD 实施记录

## 已完成

- 建立独立的 `Assets/TOD` Runtime、Editor、Shader、Profile、Prefab 结构。
- 所有视觉 Float 支持“0–24 小时曲线 / 固定数值”切换。
- 所有视觉颜色支持“HDR Gradient / HDR 单色”切换。
- `ExecuteAlways` 控制器支持编辑模式实时预览、24→0 循环、暂停/播放以及独立时间倍率。
- 太阳和月亮使用非关键帧的程序化圆环轨迹，支持方位、倾角、正午时间和月亮偏移。
- 选中 TOD Rig 时显示黄色虚线天体轨道 Gizmo。
- 控制主方向光的方向、颜色、强度与阴影强度。
- 动态天空包括三段天空色、地平线、太阳、月亮、星空、程序化云和美术颜色校正。
- 线性雾与高度雾通过 URP 全屏 Pass 在透明物体之前应用。
- Inspector 已区分“挂点临时控制”和“Profile 可保存参数”，并用大标题、边框和分割线整理。
- Profile 数值模式的变量名支持按住左右拖动，Shift 可进行精细调整。
- TOD 编辑窗口默认尺寸为 1320×800，最小尺寸为 1080×680。
- 左栏双击 Profile 会直接加载；切换后中间面板会重置并刷新。
- 曲线画布支持时间轴、节点标签、双击跳转、二维拖动、Shift 轴约束和 Esc 取消。
- Gradient 使用 Unity 原生编辑器，并提供按小时显示和拖动的色键。
- 所有 Profile 修改均接入 Unity Undo/Redo，并实时刷新 Inspector、场景与 Game 视图。
- 新建 Profile 默认定位到 `Assets/TOD/Profiles`。
- 默认 TOD Prefab 会保存动态天空材质引用并自动应用 Skybox。

## 本轮问题对应

1. **Profile 无法加载**：左栏列表改为明确区分选择和加载，双击执行加载；加载目标为当前
   选中的 TOD Rig，若未选中则自动寻找场景中的 TODController。
2. **中间画布不符合预期**：不再只使用普通 PropertyField，改为 0–24 小时自绘曲线与节点。
3. **双击节点不跳时间**：曲线节点和 Gradient 色键均支持双击跳转。
4. **切换后显示旧参数**：切换时清空旧节点选择并回到新 Profile 的首个可调参数。
5. **窗口太小**：提高默认尺寸与最小尺寸。
6. **Inspector 层级不清晰**：临时控制、场景引用、Profile 参数分成独立框体；大类标题加粗放大。
7. **变量名不能拖数值**：固定数值模式的标签支持 Unity 风格水平拖动。
8. **新建路径错误**：默认路径改为 `Assets/TOD/Profiles`。
9. **天空内容不足**：补充方向性散射、地平线太阳辉光、色调校正、星空和程序化云。
10. **文档语言**：使用说明、实施记录与待确认问题均改为中文。

## 架构选择

- 曲线键直接保存小时值，避免编辑器与运行时反复做隐藏换算。
- Gradient 键使用 Unity 原生格式保存，保证原生 Gradient 编辑器、序列化和 Undo 稳定。
- 轨道参数与 Profile 曲线分离，确保太阳/月亮始终遵循连续圆环轨迹。
- 程序化星空和云层不依赖贴图，方便项目预研与美术快速定风格；后续仍可替换为纹理或体积实现。
- 雾 Pass 截止在透明渲染之前。透明 Shader 可显式接入共享雾参数，不强制二次全屏合成。
- 自动安装器只扫描 `Assets` 内的 Renderer Data，不再修改 Package Cache 中的 URP 包资源。

## 已参考的方案

- 项目外 AC 文件夹：重点分析天空、Atmosphere、Stars、SimpleClouds Shader 的参数组织与表现思路。
- Unreal Sky Atmosphere / Day Sequence：参考 Actor、天空、方向光、雾的职责拆分。
- Ultra Dynamic Sky：仅作为工作流和美术可调性的产品标杆。
- Unity URP RenderGraph 自定义 Pass：用于雾 Pass 的注入与相机颜色中间纹理处理。

本模块未复制 AC 或 Ultra Dynamic Sky 的代码。
