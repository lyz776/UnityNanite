# TOD 实施记录

## 已完成

- 建立独立的 `Assets/TOD` Runtime、Editor、Shader、Profile、Prefab 结构。
- 所有视觉 Float 支持“0–24 小时曲线 / 固定数值”切换。
- 所有视觉颜色支持“HDR Gradient / HDR 单色”切换。
- `ExecuteAlways` 控制器支持编辑模式实时预览、24→0 循环、暂停/播放以及独立时间倍率。
- 太阳和月亮使用非关键帧的程序化圆环轨迹，支持方位、倾角、正午时间和月亮偏移。
- 选中 TOD Rig 时显示黄色虚线天体轨道 Gizmo。
- 控制主方向光的方向、颜色、强度与阴影强度。
- 动态天空包括三段天空色、地平线、太阳、月亮、星空、程序化云和美术颜色校正。
- 线性雾与高度雾通过 URP 全屏 Pass 在透明物体之前应用。
- Inspector 已区分“挂点临时控制”和“Profile 可保存参数”，并用大标题、边框和分割线整理。
- Profile 数值模式的变量名支持按住左右拖动，Shift 可进行精细调整。
- TOD 编辑窗口默认尺寸为 1320×800，最小尺寸为 1080×680。
- 左栏双击 Profile 会直接加载；切换后中间面板会重置并刷新。
- 曲线画布支持时间轴、节点标签、双击跳转、二维拖动、Shift 轴约束和 Esc 取消。
- Gradient 使用 Unity 原生编辑器，并提供按小时显示和拖动的色键。
- 所有 Profile 修改均接入 Unity Undo/Redo，并实时刷新 Inspector、场景与 Game 视图。
- 新建 Profile 默认定位到 `Assets/TOD/Profiles`。
- 默认 TOD Prefab 会保存动态天空材质引用并自动应用 Skybox。

## 本轮问题对应

1. **Profile 无法加载**：左栏列表改为明确区分选择和加载，双击执行加载；加载目标为当前
   选中的 TOD Rig，若未选中则自动寻找场景中的 TODController。
2. **中间画布不符合预期**：不再只使用普通 PropertyField，改为 0–24 小时自绘曲线与节点。
3. **双击节点不跳时间**：曲线节点和 Gradient 色键均支持双击跳转。
4. **切换后显示旧参数**：切换时清空旧节点选择并回到新 Profile 的首个可调参数。
5. **窗口太小**：提高默认尺寸与最小尺寸。
6. **Inspector 层级不清晰**：临时控制、场景引用、Profile 参数分成独立框体；大类标题加粗放大。
7. **变量名不能拖数值**：固定数值模式的标签支持 Unity 风格水平拖动。
8. **新建路径错误**：默认路径改为 `Assets/TOD/Profiles`。
9. **天空内容不足**：补充方向性散射、地平线太阳辉光、色调校正、星空和程序化云。
10. **文档语言**：使用说明、实施记录与待确认问题均改为中文。

## 第二轮天空与刷新修正

- 修复从 TOD 窗口加载新 Profile 后，TODController Inspector 继续持有旧
  `SerializedObject` 的问题。Inspector 每次绘制都会核对实际 Profile 引用，加载时还会
  记录 Prefab Instance Override 并强制重建 Inspector Tracker。
- 太阳/月亮尺寸改为按近似角半径计算，旧值不会再被平方放大成巨型圆盘。
- 太阳强度为 0 时不再用黑色圆盘覆盖天空；太阳增加暖白核心、彩色边缘和独立光晕层次。
- 月相改为月面球形法线与虚拟光方向的点积结果：0 为新月、0.5 为半月、1 为满月。
- 月亮暗面采用带天空底色的柔和地光，不再生成纯黑切片。
- 调整绘制顺序，星星先于太阳/月亮绘制，不再直接穿透月面。
- 地平线宽度使用 `abs(viewDirection.y)` 构造以 y=0 为中心的对称带，同时控制天空与
  下半球的过渡范围。
- 云层改为双层 FBM 加 Domain Warp，并加入细节侵蚀、厚度阴影和重新标定后的 Coverage。
- 删除编辑界面的环境光参数栏，并停止 TOD 对 `RenderSettings` 环境光的覆盖；保留
  主方向光颜色、强度和阴影控制。
- Default TOD Profile 升级为第 4 版生成预设：降低黎明纯红和正午紫色散射，减少星星密度，
  调整太阳/月亮尺寸，并为天空下半球提供随时间变化的颜色。

本轮使用 Unity 离屏相机分别渲染黎明、正午、黄昏、月亮近景和云层覆盖率测试图，
不只进行编译检查。

## 地平线竖向亮柱修正

- 原因：旧的“地平线聚焦”只对视线与太阳的 XZ 方位夹角做幂运算，纵向范围仍使用完整
  地平线宽度。聚焦值越大，横向越窄，于是形成明显的竖直光柱。
- 修正：将它拆成宽横向方位光瓣与独立的窄纵向高斯衰减，最终得到沿地平线展开的椭圆光斑。
- 纵向宽度设有上限，不会因为把地平线宽度拉大而重新扩展成竖柱。
- 当太阳接近天顶、XZ 投影没有稳定方位时，地平线定向光斑会自动淡出。
- 编辑器参数改名为“地平线横向聚焦”，明确该值只控制沿地平线的聚焦程度。

## Frostbite 高空云与天体表现升级

- 阅读并核对 Frostbite《Physically Based Sky, Atmosphere and Cloud Rendering》关键页，
  2D 高空云改用参与介质结构：RGB 散射系数、吸收系数、消光系数与
  Beer-Lambert 透射率。
- 单段云层光照采用解析积分
  `S * (1 - exp(-sigmaE * d)) / sigmaE`，避免先散射或先遮挡造成的明显能量偏差。
- 云光照使用前向、后向双瓣 Henyey-Greenstein 相位函数，并分别接收太阳和月亮；
  另提供环境补光、多重散射近似与地平线空气透视。
- 高空云仍保持 2D 单层预算，但云高会参与视线与云层的交点计算；新增光学厚度、
  地平线/天顶密度、纬度渐变、细节尺度、侵蚀和扭曲等美术参数。
- 天空米氏散射新增各向异性 G、光学厚度、地平线气溶胶增强和月光散射，保留可调颜色，
  同时不再把“散射”简化成单个方向点积幂。
- 星星使用独立哈希生成尺寸与亮度差异，并保留少量稀有大星，不再整齐等大。
- 月亮新增月相柔边、月相旋转、地照暗面、程序化月面明暗、细节尺度和地平线融合；
  白天与地平线附近不再像一块直接贴在天空上的纯色圆片。
- 将大气背景与太阳、月亮、星星的天体层分离；云层会用覆盖率和更长光学路径优先衰减
  天体圆盘，云体可真正遮住天体，同时允许薄云边缘保留柔和透光与银边。
- 太阳和月亮圆盘柔边的编辑范围扩大，云高范围扩大到 0.1–50 km。
- TOD 编辑器中，拖动或填写曲线/Gradient 节点不再改变预览时间；只有双击节点和
  拖动时间轴会跳时，这些预览跳时不进入 Undo，Profile 数据修改仍正常入栈。
- 默认 Profile 升级为第 5 版生成预设，并写入所有新增参数的稳定默认值。

本轮继续使用 Unity GPU 离屏相机验证黎明、正午、黄昏、月亮近景、星星随机尺寸和
不同云覆盖率；同时完成批处理脚本编译与 Shader 实际渲染检查。

## 高空云分组、四向染色与云阴影

- 将原有平铺的云参数合并为一级“高空云”，内部建立“颜色、形态、分布、光照、光学、
  云阴影”六个二级折叠目录；Inspector 与 TOD 三栏编辑器共用相同结构。
- 在物理散射结果上叠加 Front Lit、Front Dark、Back Lit、Back Dark 四向颜色，
  根据太阳与视线关系、局部密度和受光强度混合；“四向染色权重”可退回原有整体亮暗色。
- 新增 Rim 颜色、强度、朝向聚焦与宽度。Rim 只在真实云遮罩边缘出现，不会越过
  地平线产生竖向噪声条带。
- 新增 `TODCloudShadowRendererFeature` 与 `TODCloudShadow.shader`：通过深度重建
  世界坐标，沿太阳方向投影到高空云层，并对不透明场景施加动态程序化云影。
- 云阴影可调阴影染色、世界尺度、晴天/阴天强度、柔和度和最大距离；夜晚、
  天空像素和超过最大距离的像素自动跳过。
- 安装器改为逐个补齐 Renderer Feature，不再因为已经存在雾 Feature 就跳过云阴影；
  Default Profile 升级为第 6 版。
- 2D 云明暗分区的美术控制参考：
  https://zhuanlan.zhihu.com/p/697474285

## 架构选择

- 曲线键直接保存小时值，避免编辑器与运行时反复做隐藏换算。
- Gradient 键使用 Unity 原生格式保存，保证原生 Gradient 编辑器、序列化和 Undo 稳定。
- 轨道参数与 Profile 曲线分离，确保太阳/月亮始终遵循连续圆环轨迹。
- 程序化星空和云层不依赖贴图，方便项目预研与美术快速定风格；后续仍可替换为纹理或体积实现。
- 雾 Pass 截止在透明渲染之前。透明 Shader 可显式接入共享雾参数，不强制二次全屏合成。
- 自动安装器只扫描 `Assets` 内的 Renderer Data，不再修改 Package Cache 中的 URP 包资源。

## Lens Flare 与雾系统第一阶段

- 太阳 / 月亮挂点接入 Unity URP 原生 `LensFlareComponentSRP`，使用零强度禁用方向光
  保持无限远天体投影，同时不增加场景光照。
- Profile 新增 Lens Flare 强度、尺寸、遮挡半径、采样数、环境遮挡、屏外光斑和衰减距离；
  默认 Rig 自动使用 URP 包内置 Lens Flare Data，美术可替换为自定义资产。
- 雾界面重构为一级“雾”和“常规距离雾、屏幕空间散射、贴地体积雾（预研）”三级子栏。
- 常规雾新增 Top / Bottom 颜色和强度、天空参与量、Power、线性 / 指数连续混合，以及
  世界高度衰减；不再用单一颜色把天空和地面统一盖住。
- 屏幕空间散射使用 8 邻域深度感知滤波，按距离渐入并提供前后景深度阈值，默认关闭。
- 贴地体积雾建立地形高度图场景入口以及密度、雾高、2D / 3D 噪声、侵蚀、风、
  相位函数、体积阴影、丁达尔光和步进数等 Profile 数据；本阶段不伪造体积结果。
- 新增中文预研文档 `FOG_AND_LENS_FLARE_PLAN.md`，明确高度图、密度场、单次散射、
  主光阴影、低分辨率积分、时域重建和透明合成的后续顺序。
- Default Profile 升级为第 7 版。

## 风格化云光照第二阶段

- 阅读用户提供的 StylizedWeather 使用手册并核对商店成片。手册公开的是逐小时材质、
  天气数据表、太阳 / 天光 / 雾颜色联动和曲线工作流，没有包含 Shader 节点、贴图或
  材质内部算法；本模块据此沿用更适合 Unity 的 Profile 架构，并按成片独立实现视觉目标。
- 视觉目标为大片云体内部层次、冷暗云底、暖色逆光透射和宽范围天空太阳染色，
  不把第三方资源文件重新打包或分发到项目中。
- 高空云增加沿太阳平面方向的低频密度探针，在不进行完整体积 Ray March 的前提下近似
  云体内部自遮挡；太阳较低时自动拉长采样距离。
- 增加包裹光、自遮挡强度 / 距离、分段光照权重、色阶数、色阶柔度、云底暗面、
  太阳透光强度和方向聚焦等可曲线化参数。
- 分段光照不是简单硬 Posterize：每个色阶边界保留可调平滑区，并可与连续物理光照混合。
- 暖色透光使用中等光学厚度窗口，只在云边和薄云中明显，避免整块厚云变成自发光贴片。
- 天空新增宽域太阳染色颜色、强度、聚焦和地平线权重，补足太阳周围大范围的空气感；
  原有米氏散射和窄光晕继续负责物理特征与高光核心。
- 天顶与地平线的云层投影尺度重新标定，地平线不再因为视线分母过小碎成高频条带；
  默认云增加细节侵蚀、光学厚度、自遮挡和四向染色权重。
- 分段受光不仅改变四向色，还会调制散射能量与云体细节，避免大片云只像单色剪影。
- Default Profile 升级为第 10 版。

## StylizedWeather 资源对照与高空云第三阶段

- 使用 UE 5.3 只读载入用户提供的 `M_Sky`、`MI_Sky_Afternoon00` 与
  `MF_CloudLayer`，导出 264 个母材质表达式和实例的有效参数值。
- 原材质的云形核心不是多层 FBM：主形状与高频细节复用 `T_Noise001`，
  `T_Noise002` 只负责低频不均匀度；实例的代表值为 Detail Size 12、
  Detail Strength 0.15、Light UV Offset 0.025、Rim Contrast 0.3。
- Unity 版本接入用户导出的两张噪声图，并保留无贴图时的程序化回退。
- 云保持固定高度水平平面投影；曾尝试的球面经纬 UV 会产生天顶极点，已完全撤销。
  远景纹理恢复隐式 mip 采样，修复地平线处的竖向条带与高频闪烁。
- Rim 改为在同一水平云平面上沿太阳方向偏移遮罩后做差，只保留真正朝向太阳的边缘。
- 编辑器隐藏重复的整体暗色、四向染色权重和 Rim 聚焦参数；旧字段继续序列化，
  保证已有 Profile 可加载。四向颜色成为唯一的风格化明暗调色板。
- Default Profile 升级为第 11 版；迁移只改云投影相关参数，不覆盖已有天空、天体和雾调色。

## 高空云第四阶段：双层与闪电

- 对照 `MI_Sky_Afternoon00` 的 `SecondLayerFog`、`ThunderAlpha`、`GlowSpeed`、
  `ThunderColor` 等参数，加入第二个独立水平云平面以及可选的云内闪电。
- 第二层拥有独立高度、尺度、速度、覆盖偏移、混合强度和远景雾化；两层固定旋转错开，
  避免复用同一噪声图时图案重合。云阴影同步合成两层遮罩。
- 闪电复用导出的 `T_GlowPos.EXR` 作为不规则空间遮罩，短时多脉冲只照亮云体，
  不绘制突兀的屏幕广告牌闪电。开关、颜色、强度、频率、时长和尺度均进入 Profile。
- Beer-Lambert 真实透射率与美术不透明度分离，相位函数补上 `1 / 4π` 归一化；
  覆盖率为零时天空云和云阴影均严格为零。Default Profile 版本升级为 12。

## 高空云第五阶段：覆盖率、云影与测试工具

- 覆盖率改为非线性面积阈值，不再用低覆盖率阶段的整体 Alpha 淡出；`0` 仍严格无云，
  `0.08` 一类小值现在只留下少量高密度云块。
- 第二层改为完全独立覆盖率。旧 `coverageOffset` 仅保留反序列化兼容，版本 13 迁移时
  会将旧的“主覆盖率 + 偏移”结果换算成第二层初始覆盖率，之后两层互不约束。
- 水平云平面保持真实投影直到距地平线不足约一度；只在交点已经达到数百公里的极远区域
  才快速淡出，并把距离封顶区完全藏住。这样保留绝大部分远景云，同时不暴露冻结 UV 的竖向拉伸。
- 高空云升级为可调球形云壳：曲率 `1` 近似地球半径，`0` 可切回平面，较大值可强化风格化
  的远景下弧。球壳交点在地平线处保持有限距离，因此可以保留贴近地平线的远云而不产生竖帘。
- 云图采样加入相机世界 XZ 坐标（默认按 1 Unity 单位 = 1 米换算），玩家在世界中移动时会穿过
  固定于世界空间的云场；风速只负责云自身随时间移动，不再与相机移动混为一体。
- 高空云新增近处覆盖率、远处覆盖率及以公里为单位的混合起止距离。远近共用同一套世界空间
  UV、形态、柔边和着色，只对覆盖率对应的阈值插值，避免过渡带出现变形或材质质感突变。
- 闪电发光遮罩不再乘云层 UV 无限重复，而是在世界空间云壳上生成单个有边界的局部区域；
  发光贴图改为 Clamp，流速只产生局部周期扰动，不会形成放射纹或随运行时间漂出有效范围。
- 隐藏重复的太阳/月亮云光照、分段光照权重和云底暗面强度，运行时使用经过调校的固定值；
  Profile 中保留旧字段只用于兼容已有资源。
- 云主体在有作者贴图时不再同时执行 FBM 回退；云影从每像素两套四层 FBM 和多张贴图，
  降为每个启用云层一次主形状采样，关闭、夜间或零覆盖率时 Renderer Feature 不入队。
- 云影用深度导数重建表面法线并读取 URP 主光实时阴影，只调制仍能收到直射主光的区域；
  已在主光阴影中的像素直接跳过。陡峭表面使用主导面投影，避免 X/Z 朝向之一退化成条纹。
- URP 在本项目中没有向 Lens Flare 传环境云遮挡纹理，因此控制器以两张可读云纹理在
  太阳/月亮方向做低成本 CPU 遮挡采样，并直接衰减对应 Flare 强度。
- 闪电触发改由控制器调度：启用后最多约一秒出现首次闪光，随后按“每分钟次数”随机化
  间隔；Inspector、Profile 闪电栏和独立时间面板均提供立即测试按钮。
- 新增可停靠 `Window/Unity Nanite/TOD Time Control` 小面板，时间跳转不写 Undo，
  可随时播放、暂停、改速度、跳到 0/6/12/18 点并测试闪电。
